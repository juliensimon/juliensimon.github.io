Mistral Large 4 Weights: The Score Comes With the Harness

Author: Julien Simon

Date: November 1, 2026 · 12 min read

Source: https://www.airealist.ai/p/mistral-large-4-weights-score-comes-with-harness

Listen: AI-narrated audio of this piece, 11 min. From The AI Realist podcast, also on Apple Podcasts and Spotify.

On October 29th, 2026, Mistral committed the Large 4 weights to Hugging Face, 23 days after the preview.[1] The release page says: "On Terminal-Bench 4.0, Mistral Large 4 improved by 13 percentage points to 41% compared to its public preview, taking the lead among open-weight models".[2] Three conclusions follow.

First, the 41 is a Vibe number. Artificial Analysis (AA) measured it in Mistral Vibe, Mistral's own coding agent, the harness around the model. In a minimal, generic agent, the two independent boards, AA and Vals AI, show no gain over the Large 4 preview on Terminal-Bench, a 66-task benchmark of work in a terminal. If you plan to run them in an agent other than Vibe, the only published number is 25 or 26.

Second, the weights are open, and the license has one commercial condition. Running them for your own staff, or inside an end-user product, falls outside it. Giving third parties access to them, as an inference platform or as a consultancy handing clients an endpoint, requires a separate commercial license from Mistral, at any size.

Third, Mistral's release post sells a stack, and the 41 describes the stack. It sends you to Mistral Studio, the Mistral API, Mistral Forge, and Vibe. For an enterprise buying that stack, the score and the product match. For the community, the 41 comes only from Vibe, and Vibe draws a small share of developer attention: 5,268 GitHub stars on November 1st, 2026, versus 223,729 for Opencode and 154,130 for Claude Code.[3]

Whose number is Mistral Large 4's 41?

The chart is headed "Artificial Analysis Coding Agent Index - Terminal-Bench 4.0". In that index, AA runs each model inside a coding agent: Opencode for GLM-5.3, Claude Code for Claude, Mistral Vibe for Large 4.[4] Beside the 41% bar, a 28% bar is labeled "ML4 Preview - self reported". At launch, Mistral credited that figure to "the ArtificialAnalysis coding index", with scores "evaluated privately by Artificial Analysis ahead of the harness' public launch".[5] So the 28 was probably an AA agent run too, and the 13 points compare like with like.

Now the generic agent. AA's Intelligence Index runs Terminal-Bench's full 66-task set in mini-swe-agent, a minimal agent harness.[6] Vals AI runs the same harness at the sampling Mistral recommends.[7][8]

Outside Vibe, neither board sees a Terminal-Bench gain: Vals's 1.5-point drop sits well inside its margin, and AA's preview figure comes from an older index. Both generic runs used High effort, like the 41.[9][7]

What does a coding agent add to a Terminal-Bench score?

I call the difference between a model's score in its own agent and in mini-swe-agent its agent premium, in points. AA's two indexes give it for thirteen models.[9][4]

Large 4's agent premium is +16 points. The other twelve sit between -4 and +7, median 0. A harness alone can move a score by nine points: the StateM preprint lifts GPT-5.5 from a reference 83.1% to 92.1% on Terminal-Bench 2.1 with no change to the weights.[10] Vals prints plus or minus 5.1 points on Large 4's release score, so a premium of 5 or 7 can be noise, and 16 is hard to call noise. The best case against: both boards run mini-swe-agent, so a penalty that harness puts on Mistral's tool format would produce this table. But if the 28 was an agent run, a fixed penalty would have shown at preview. It did not: AA's agent score minus Vals's generic score was about 0 then and is about 15 now.[5]

On the Coding Agent Index's Terminal-Bench bars, the lead among open-weight models is 41 against 40 for GLM-5.3 in Opencode: one point, each model in its own agent. In mini-swe-agent, GLM-5.3 leads by 17: 42 against 25. GLM-5.3 scores 41.8 in Claude Code on the Terminal-Bench leaderboard: three agents, all within two points. Large 4 has been measured in two.[9][4][11]

What do you get with the Mistral Large 4 weights?

You get the weights. Vibe, Mistral's harness, is a separate download: it ships under Apache 2.0, and a config file sets the model provider.[11] No published run shows whether it gives 41 on weights you host: the Terminal-Bench leaderboard has no Mistral row.

Three readings fit the 13 points, and the data cannot tell them apart. Mistral credits "three weeks of additional reinforcement learning", reports gains beyond coding, and does not name its training tasks.[2]

  1. The RL used agent tasks shaped like Vibe's, so the model gained a skill that does not transfer to a minimal agent.

  2. The harness improved or sets the model up differently, with a different thinking budget or sampling: Vibe went from version 2.26 on October 6th to version 3.0 on October 19th, and AA's data records Vibe 3.0 for the 41, while the 28 names no version. Vibe at Medium effort scores 26.26, level with the generic runs.[12]

  3. Both. A run outside Vibe at 38 or more would put the gain in the weights; at 25 to 30, in Vibe or in training on it.

Mistral Large 4's modified MIT license, read

Mistral's post calls the license a modified MIT with one condition.[13] It applies if you or any affiliate operates a "Model as a Service" business: giving a third party access to the weights or a derivative, for inference or post-training, with "meaningful control over the inputs, parameters, or training data". Any commercial use then needs a license from Mistral. Out of scope: "end-user products with model capabilities solely embedded within specific features or harnesses", and mere relaying.

My reading of the text: an inference platform is in. So is a consultancy that hands a client an endpoint on fine-tuned weights, because the client controls the inputs, or lets the client fine-tune them.

Kimi K3's license has the same Model as a Service definition and exclusions, but applies it only above $20 million of revenue over twelve months, and the remedy is a separate agreement with Moonshot. GLM-5.3's applies above $10 billion, and the remedy is a security review by Z.AI, not a license. DeepSeek V4.1 Flash is plain MIT.[14] Mistral's has no revenue floor. Of the four licenses, Mistral's reaches the most businesses.

Mistral Large 4's configuration file, opened

Large 3's configuration matched DeepSeek-V3's width, depth, and attention settings.[15] Large 4's does not: 6,144 wide against 7,168, 72 layers against 61, experts 6,144 wide against Large 3's 4,096, a different vocabulary.[16][15] It keeps DeepSeek's designs: latent attention, a shared expert and a sparse-attention indexer.

Mistral Large 4 against my October 9th marks

On October 9th I set three marks for October 31st: public weights, a permissive license file, and 38 or more on Artificial Analysis. The weights are public, and the license carries one condition. We can't score the third because AA changed its index in October. I also listed three things a buyer needs. The license is out and, by Mistral's account, so is a better checkpoint; the token count is still missing. The Terminal-Bench figure I flagged as the one mismatch has an explanation: Mistral's launch footnote credited its 28.3% to AA's coding index, an agent run, while the boards' figures came from a generic harness.[15]

Two things would settle it: an independent run of the released weights in a non-Mistral agent, or a technical report that names the setup behind the 28 and the 41.

Until then, when a lab hands you a benchmark, ask which agent was driving.
